# Changelog 2026-11-09 / 11-10 (v1.4.0)

The week-of-11-09 work that goes into v1.4.0. Per-feature details: docs/netplay.md, docs/survival.md, docs/weapons.md,
docs/vr.md, docs/quest.md, docs/subtitles.md, docs/translating.md.

## Online without port forwarding (natpunch, natpunch2)

| | Before | After |
|---|---|---|
| A friend behind a router without UPnP / a forwarded port | could not join (the host's router dropped the packets) | the same Join Code; the game asks a public STUN server for each PC's address and punches through (both sides send); direct first |
| Strict routers | - | the friend's page shows a 20-letter Reply Code; the host pastes it in the waiting room |
| 3-4 PCs | one code exchange per friend | the host pastes the whole group-chat stretch once: every reply code in it is found (checksummed, duplicates ignored) |
| Public IPs in hotd.log | printed | `public#XXXX` (LAN / loopback kept; HOTD_NET_LOG_IPS=1 for dev) |
| End of a 3-4 PC game | a joiner one frame early was dropped ("player 3 left (frame 2999)", 1 in 4 runs) | the seat kept until a real leave or 6 s of silence (4 / 4 runs ok) |

Online Co-op > Address Lookup (On; Off = the old behaviour). No relay, no lobby: very strict NAT still needs UPnP /
port forwarding. Tests: STUN encode / decode vs RFC 5769, a mock STUN server, `module.online_punch` (two instances behind
a simulated restricted NAT, 3000 frames in sync), a 3-PC script with one combined paste.
