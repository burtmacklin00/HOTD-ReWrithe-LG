## Found on the way

- R1's runtime versions (src/game) differed from the disassembly: object_draw writes the draw param's light record
  (0x520A40 + 12 x param, 3 words to the geometrizer) before and record 0 after; object_draw_model places the model
  (T, R, S) and draws a shadow pass (flags2 bit 1: stored matrix 3); body_draw calls draw_fade_begin(fade) first and
  geo_send_words(0, 31, 0x7A0) after when fade != 0xFF; part_draw draws the shadow pass after the hook (table
  0x14BA80[type][role] or the part's model). Part offsets in the part data are floats (not ints).
- hotd_proof now maps main_data (0x2000000 and the upper half at 0x6000000) and prints differences per routine.
- capture_lists.py counts only non-virtual members as ported: the ported routines kept virtual here (so the runtime's
  overrides still compile) show up in its -Boundary list and must be removed by hand. Unanalysed routines (kind 96's
  frames) need an explicit `addr:size` in both -Funcs and -Ported.
