The House of the Dead: ReWrithe - Thank you / Credits
=====================================================

Thank you for playing. This is an unofficial fan project, made to keep a great game
playable and to show how it works. It is not affiliated with or endorsed by SEGA.


THE ORIGINAL GAME
-----------------
The House of the Dead
  SEGA AM1 - arcade (Sega Model 2), 1996
  PC port, 1998
Everyone who made it: thank you for the game this whole project is built around.


THIS PROJECT
------------
Project author, testing, direction ... Tawhid
Translations ......................... machine-made (Korean, Japanese, Arabic, Hebrew):
                                       corrections/additions are welcomed and highly encouraged

AI disclaimer: ReWrithe was made with AI assistance: AI tools helped reverse engineer the
original game and combine its code to bring the arcade and PC versions together. No
generative AI has been or ever will be used to create artistic assets. Everything you
see and hear comes from the original games or from human-made work. Any new model,
texture or sound effect will always be made by humans.

and a short note of what you did. Never attach ROMs or game files.
